# Sales Dashboard Using Excel

## Overview
An interactive Excel dashboard built on 2,000 sales orders. It turns raw order data into charts and numbers that show how the business is doing.

## Project Objective
To answer common sales questions quickly: how much did we earn, where, through which channel, and which products sell best.

## Key Features
- **KPI Cards:** Total revenue, total orders, quantity sold, and average order value.
- **Revenue Trends:** Monthly revenue over time.
- **Breakdowns:** Revenue by region, product category, and sales channel.
- **Top Products:** The top 5 products by revenue.
- **Interactive Filters:** Slicers and a date timeline let you filter the whole dashboard in one click.
- **Data Checks:** Cleaned the data first (no blank headers, correct date and number formats, consistent categories).

## Tools and Techniques
- Microsoft Excel
- PivotTables (9 supporting pivots)
- PivotCharts and Charts (5)
- Slicers and Timeline
- Data Cleaning and Validation
- Dashboard Planning (mapping each business question to a column and a visual)
